# 帝王模拟器 · 千秋

一款「模拟人生」式的纯前端文字模拟游戏：扮演一位女帝，按月理政，在朝臣、后宫、宗室、藩王与邻国之间纵横捭阖。死亡不一定是终点——若有储君在册，帝位将世代传承，你的功过会被写入国史本纪。

## 在线游玩

部署于 GitHub Pages，打开即玩，无需安装。

## 玩法

- **开局**：一问一答定制你的皇帝（姓名/国号/年号/年龄/都城/国家背景，四种背景各有优劣）
- **回合制**：每月为 1 回合，每回合从 12 项行动中选 3 项（上朝/召见大臣/巡营/入后宫/批阅奏折/设宴/暗查/修养/出巡/祭祀/教导皇嗣/邻国事务），也可自由输入指令
- **所有剧情都由你拍板**：游戏绝不替你做决定——
  - **上朝**：臣子当廷上奏（沈素奏礼制、萧破军讨军费、御史弹劾、户部亏空……），奏对完毕由你裁决，不同选择引发不同朝堂反应
  - **入后宫**：先选去处（皇后/贵君/侍君寝宫或太后请安），再演一段符合人物性格的独处剧情——与温和的皇后对弈谈家事、听聪慧的贵君以琴喻事、陪沉静的江雪楼抄经、应付骄纵裴镜的争宠告状，调情、议事、托付求助皆由你回应
  - **召见大臣/设宴/暗查/邻国事务/教导皇嗣**：同样是「演绎 → 你定夺」的两段式
  - **NPC 请示**：大臣奏请扩军、丞相条陈时政、后宫风波请示、萧破军献马……一律呈到你面前等你批复
- **数值系统**：帝王六维（威严/手腕/仁德/韬略/精力/心性）+ 国力六项（国库/军队/民心/权臣/后宫/藩王），每次决断明确标注增减与理由
- **自由批复语义解析**：任何「自行决断」都不是摆设——系统会把你的措辞解析为意图（从严/从宽/查究/应允/拒绝/赏赐/亲昵/敲打/搁置/动武/用度……）与语气强度（“从重”加码、“酌情”减半），**生成与你批复相对应的结果叙述，加减的数值也跟着你的措辞走**；涉及具体人物时，对方会按自己的性格给出反应（沈素端方、萧破军豪迈、皇后温和、谢兰因聪慧、裴镜骄纵、江雪楼沉静）
- **随机事件**：每月月末触发 12 类事件（边关军情/地方叛乱/天灾/朝臣争斗/后宫风波/民生舆情/暗杀宫变/祥瑞大凶/邻国异动/宫闱秘案/皇嗣夺嫡/藩王异动），快捷倾向按钮或自由文字处置，**没有唯一真相**——可能错判、可能留患，未了结的事件会持续发酵；处置之外你在措辞里夹带的安排（如“从严之外再命人暗查”）会被单独结算
- **NPC 生态**：丞相沈素、大将军萧破军、掌印太监怀恩、太后与后宫诸君各有忠心/野心/宠爱，剧情严格贴合原设性格；萧破军野心过高可能发动兵变
- **皇嗣培养**：过继宗室女为皇嗣，教导智/武/德/胆/心性五维，16 岁后可册立储君或分封藩王
- **多代传承**：驾崩后若有继承人，新帝按培养属性换算六维，继承先帝留下的国库军队民心；明君/暴君会给新帝带来世代加成或流毒；历代帝王本纪归入国史，可随时调阅
- **结局体系**：民心尽失、权臣篡位、兵变、精力衰竭、丹药中毒……每种死法有专属场景、谥号与功过总结
- **存档**：localStorage 自动存档，可随时「继续前朝」

## 技术

纯静态站点：HTML + CSS + 原生 JavaScript，无构建、无依赖。

```
emperor-game/
├── index.html      # 页面骨架（开场/开局向导/主界面/结局）
├── css/style.css   # 古风 UI（朱砂+鎏金+宣纸）
└── js/
    ├── data.js     # 设定库：NPC/行动模板/12类事件/结局文案
    ├── engine.js   # 游戏引擎：回合/结算/事件处置/死亡与传承判定
    └── ui.js       # 渲染层：三栏面板/叙事卡片流/结局画面
```

本地运行：直接用浏览器打开 `index.html` 即可。
