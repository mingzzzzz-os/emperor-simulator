# 帝王模拟器 · 千秋

一款「模拟人生」式的纯前端文字模拟游戏：扮演一位女帝，按月理政，在朝臣、后宫、宗室、藩王与邻国之间纵横捭阖。死亡不一定是终点——若有储君在册，帝位将世代传承，你的功过会被写入国史本纪。

## 在线游玩

部署于 GitHub Pages，打开即玩，无需安装。

## 玩法

- **开局**：一问一答定制你的皇帝（姓名/国号/年号/年龄/都城/国家背景，四种背景各有优劣）
- **回合制**：每月为 1 回合，每回合从 12 项行动中选 3 项（上朝/召见大臣/巡营/入后宫/批阅奏折/设宴/暗查/修养/出巡/祭祀/教导皇嗣/邻国事务），也可自由输入指令
- **数值系统**：帝王六维（威严/手腕/仁德/韬略/精力/心性）+ 国力六项（国库/军队/民心/权臣/后宫/藩王），每次行动明确标注增减与理由
- **随机事件**：每月月末触发 12 类事件（边关军情/地方叛乱/天灾/朝臣争斗/后宫风波/民生舆情/暗杀宫变/祥瑞大凶/邻国异动/宫闱秘案/皇嗣夺嫡/藩王异动），自由文字处置，**没有唯一真相**——可能错判、可能留患，未了结的事件会持续发酵
- **NPC 生态**：丞相沈素、大将军萧破军、掌印太监怀恩、太后与后宫诸君各有忠心/野心/宠爱，会主动搞事；萧破军野心过高可能发动兵变
- **皇嗣培养**：过继宗室女为皇嗣，教导智/武/德/胆/心性五维，16 岁后可册立储君或分封藩王
- **多代传承**：驾崩后若有继承人，新帝按培养属性换算六维，继承先帝留下的国库军队民心；明君/暴君会给新帝带来世代加成或流毒；历代帝王本纪归入国史，可随时调阅
- **结局体系**：民心尽失、权臣篡位、兵变、精力衰竭、丹药中毒……每种死法有专属场景、谥号与功过总结
- **存档**：localStorage 自动存档，可随时「继续前朝」

## 技术

纯静态站点：HTML + CSS + 原生 JavaScript，无构建、无依赖。

```
emperor-game/
├── index.html      # 页面骨架（开场/开局向导/主界面/结局）
├── css/style.css   # 古风 UI（朱砂+鎏金+宣纸）
└── js/
    ├── data.js     # 设定库：NPC/行动模板/12类事件/结局文案
    ├── engine.js   # 游戏引擎：回合/结算/事件处置/死亡与传承判定
    └── ui.js       # 渲染层：三栏面板/叙事卡片流/结局画面
```

本地运行：直接用浏览器打开 `index.html` 即可。
