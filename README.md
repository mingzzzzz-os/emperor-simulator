# 帝王模拟器 · 千秋

一款「模拟人生」式的纯前端文字模拟游戏：扮演一位女帝，按月理政，在朝臣、后宫、宗室、藩王与邻国之间纵横捭阖。死亡不一定是终点——若有储君在册，帝位将世代传承，你的功过会被写入国史本纪。

## 在线游玩

部署于 GitHub Pages，打开即玩，无需安装。

## 玩法

- **开局**：一问一答定制你的皇帝（姓名/国号/年号/年龄/都城/国家背景，四种背景各有优劣）
- **回合制**：每月为 1 回合，每回合从 12 项行动中选 3 项（上朝/召见大臣/巡营/入后宫/批阅奏折/设宴/暗查/修养/出巡/祭祀/教导皇嗣/邻国事务），也可自由输入指令
- **所有剧情都由你拍板**：游戏绝不替你做决定——
  - **上朝**：臣子当廷上奏（沈素奏礼制、萧破军讨军费、御史弹劾、户部亏空……），奏对完毕由你裁决，不同选择引发不同朝堂反应
  - **入后宫**：先选去处（皇后/贵君/侍君寝宫或太后请安），再演一段符合人物性格的独处剧情——与温和的皇后对弈谈家事、听聪慧的贵君以琴喻事、陪沉静的江雪楼抄经、应付骄纵裴镜的争宠告状，调情、议事、托付求助皆由你回应
  - **调戏与纳新**：对后宫诸君可以亲昵、议事，也可以直接调戏——皇后会脸红，谢兰因会把话头递回来，江雪楼耳根通红，裴镜顺杆就爬；出巡（校场英朗教头、茶棚狂生）、设宴（伶俐商贾、温润医者）、艳遇事件（灯市惊鸿、画舫琴音）中还能邂逅良家郎君（均已成年），纳入后宫后各有专属性格剧情
  - **召见大臣/设宴/暗查/邻国事务/教导皇嗣**：同样是「演绎 → 你定夺」的两段式
  - **NPC 请示**：大臣奏请扩军、丞相条陈时政、后宫风波请示、萧破军献马……一律呈到你面前等你批复
- **数值系统**：帝王六维（威严/手腕/仁德/韬略/精力/心性）+ 国力六项（国库/军队/民心/权臣/后宫/藩王），每次决断明确标注增减与理由
- **自由批复语义解析**：任何「自行决断」都不是摆设——系统会把你的措辞解析为意图（从严/从宽/查究/应允/拒绝/赏赐/亲昵/敲打/搁置/动武/用度……）与语气强度（“从重”加码、“酌情”减半），**生成与你批复相对应的结果叙述，加减的数值也跟着你的措辞走**；涉及具体人物时，对方会按自己的性格给出反应（沈素端方、萧破军豪迈、皇后温和、谢兰因聪慧、裴镜骄纵、江雪楼沉静）
- **随机事件**：每月月末触发 14 类事件（边关军情/地方叛乱/天灾/朝臣争斗/后宫风波/民生舆情/暗杀宫变/祥瑞大凶/邻国异动/宫闱秘案/皇嗣夺嫡/藩王异动/艳遇），小说化叙事、人物轮番登场；快捷倾向按钮或自由文字处置，**没有唯一真相**——可能错判、可能留患，未了结的事件会持续发酵；处置之外你在措辞里夹带的安排（如“从严之外再命人暗查”）会被单独结算
- **科举取士**：每三年三月春闱放榜，你亲自**钦点状元**、**定取士规模**（广取收天下士心但冗官耗帑 / 从严取精简却落第者怨 / 照顾门第则世族感恩而寒门失望）。新进士各有性格原型、籍贯与家世，入朝后即进入「召见大臣」之列，可调戏、可提拔、可外放
- **朝中关系网**：新科进士不是孤身入朝——与旧臣之间会有**座师 / 同乡 / 举荐（举主连坐）/ 姻亲 / 政敌 / 孤寒无依**等牵扯，入朝时即生效（座师得势、政敌结怨），此后还会在朝堂上继续发作：老师替门生铺路、匿名状告新进士、乡党渐成气候……
- **调戏廷臣**：对大臣说轻佻话或逼其就范，会按其**性格原型**演出完全不同的剧情，而非套用同一套模板——刚直者横笏自守、逼急了撞柱明志并上疏弹劾陛下；忠君者解官带的手抖得解不开，在「君要臣死」与「成何体统」之间撕扯；风流才子非但不躲还反撩，逼到尽头会跟你谈条件；憨直武人把命都交出来，事后却自惭辱没了军人的膝盖；清高孤介者一言不发，事后辞官披发入山；寒门隐忍者笑着应下，心里却一笔笔记账。**逼得太狠，有人会走到自己的终局**（自尽、求死沙场、反噬）
- **NPC 生态**：丞相沈素、大将军萧破军、掌印太监怀恩、太后与后宫诸君各有忠心/野心/宠爱，剧情严格贴合原设性格；萧破军野心过高可能发动兵变
- **皇嗣培养**：过继宗室女为皇嗣，教导智/武/德/胆/心性五维，16 岁后可册立储君或分封藩王
- **多代传承**：驾崩后若有继承人，新帝按培养属性换算六维，继承先帝留下的国库军队民心；明君/暴君会给新帝带来世代加成或流毒；历代帝王本纪归入国史，可随时调阅
- **结局体系**：民心尽失、权臣篡位、兵变、精力衰竭、丹药中毒……每种死法有专属场景、谥号与功过总结
- **存档与跨设备**：
  - 本机存档写进浏览器 `localStorage`，随时「继续前朝」；这个存档只属于当前设备的当前浏览器（清缓存/换浏览器会丢）
  - 想换设备接着玩，用顶栏的 **导出 / 导入**：导出得到一段 `EMPSAVE1` 开头的**存档码**（deflate 压缩 + Base64，一局通常 2–5 KB），复制发到微信/备忘录/邮件，或直接**下载存档文件**；在新设备（甚至新浏览器、清过缓存）打开游戏点「导入」，粘贴存档码或选文件即可原样接上
  - 导入会覆盖本机进度，会先给出提示；坏码会被拦下并保留原进度不动
  - 导出时若正卡在月末事件或某段剧情中间，会自动退回最近一个「可继续」的节点，避免导入后卡死

## 技术

纯静态站点：HTML + CSS + 原生 JavaScript，无构建、无外部依赖。

```
emperor-game/
├── index.html      # 页面骨架（开场/开局向导/主界面/结局/存档搬运弹层）
├── css/style.css   # 古风 UI（朱砂+鎏金+宣纸）
├── js/
│   ├── data.js     # 设定库：NPC/行动模板/事件/结局文案/场景库/意图词库
│   ├── engine.js   # 游戏引擎：回合/结算/事件处置/死亡与传承/存档码编解码
│   └── ui.js       # 渲染层：三栏面板/叙事卡片流/结局画面/导入导出弹层
└── test/
    ├── smoke.js    # 引擎冒烟测试（83 项，含 150 回合长程模拟）
    └── ui-flow.js  # UI 端到端测试（27 项，模拟「设备A导出 → 设备B导入」）
```

本地运行：直接用浏览器打开 `index.html` 即可。

### 移动端

≤760px 视口自动切换为手机布局：**顶栏（时间 + 横向滚动的国力条 + 存档按钮）+ 三标签页**。
「朝堂 / 帝王 / 人物」三个面板各自占满整屏并独立滚动，手机上也能把六维属性、国力、未结事件、朝臣后宫皇嗣国史一项项翻完。
已适配 iPhone 安全区（`viewport-fit=cover` + `env(safe-area-inset-*)`）、动态视口高度（`100dvh`，不受地址栏收放影响）、横屏矮屏压缩，并屏蔽下拉刷新与 iOS 聚焦缩放。
有待你批复的剧情（月末事件、请对、请示）出现时会自动切回「朝堂」页签，不会漏决断。桌面端三栏布局不受任何影响。

跑测试：

```bash
node test/smoke.js                          # 引擎测试 112 项，无额外依赖
npm i jsdom && node test/ui-flow.js         # UI 端到端：跨设备存档搬运 27 项
npm i jsdom && node test/ui-court.js        # UI 端到端：科举取士 + 调戏廷臣 22 项
npm i jsdom && node test/ui-mobile.js       # 手机布局结构契约 27 项
```
